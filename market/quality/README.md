# Market Census Quality

`latest_validation.json` is generated by the market census builder.

## Hard failures

The build exits non-zero for malformed input such as:

- invalid JSON
- missing required fields
- invalid `MY-FE-0001` ID format
- invalid URL/date/datetime
- duplicate vacancy ID
- duplicate vacancy URL
- duplicate evidence ID
- invalid manual override field/type

## Canonical rejection, not build failure

A structurally valid candidate is kept out of the canonical population when:

- evidence is missing
- vacancy is inactive
- title lacks the contiguous phrase `FinOps Engineer`
- title verification fails
- Malaysia verification fails
- raw/evidence URL differs
- raw/evidence source differs

These are recorded under `rejected` so the reason remains auditable.
