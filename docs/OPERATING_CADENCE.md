# FinOps Operating Cadence

This cadence is a practitioner-informed working design. It must be reconciled with vacancy data and official guidance before being treated as a standard.

## Daily

- anomaly review
- failed budget / policy alerts
- severe cost spikes
- critical unallocated spend

## Weekly

- optimization backlog
- idle / zombie resources
- rightsizing candidates
- owner follow-up
- engineering review

## Monthly

- actual vs budget vs forecast
- showback / chargeback
- savings pipeline
- commitment coverage/utilization
- tag/allocation quality
- business-unit review

## Quarterly

- architecture / TCO review
- commitment strategy
- vendor / contract / licensing review
- data-platform efficiency review
- policy effectiveness
- maturity assessment
