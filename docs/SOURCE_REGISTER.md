## Evidence grades

- **A** — direct measured production case
- **B** — official technical implementation guidance
- **C** — FinOps Foundation / industry framework
- **D** — practitioner opinion / secondary discussion

Core portfolio claims should rely mainly on Grade A/B evidence. Practitioner signals may generate hypotheses but do not prove company-specific outcomes.
