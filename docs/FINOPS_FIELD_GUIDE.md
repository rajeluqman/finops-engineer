# FinOps Field Guide

Canonical project guide scaffold.

## Purpose

Connect active Malaysia FinOps Engineer vacancy demand to FinOps framework concepts, official provider guidance, real published company cases, reproducible labs, Power BI evidence, and interview transfer.

## Learning contract

Each major topic should cover WHAT, WHY, WHEN, business question, data required, approach, cloud/platform implementation, SQL/Python/IaC, guardrail, KPI, failure modes, real case, reproduction lab, validation and interview transfer.

## Validation mindset

Cheaper is not automatically better. A change should preserve required SLA, reliability, correctness, security and compliance while improving sustainable cost/value.
